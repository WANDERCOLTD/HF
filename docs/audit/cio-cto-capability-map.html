WHAT HOLDS

The educator owns the instructional model end to end, and the engine cannot overwrite the regulated text. Hand these three documents to a human tutor and you would get a recognisable version of the same session — which is the real test of whether pedagogy lives in configuration rather than code, and it passes.

WHAT DOESN'T

The Exam Assessment promises the learner a per-objective, per-dimension breakdown and calls it “the most concrete feedback a Practitioner-tier learner will get.” It is produced in conversation and never stored. The learner is told to bring two pointers back to Revision Aid, and Revision Aid has no way to read them.

ALREADY WAITING

Checked before sizing, and it changed four of these. CallerAttribute is a free-text key / scope / JSON store with confidence and provenance on every row — the same place lo_mastery:{unit}:{lo} already lives — so a per-dimension or per-error axis is a key convention, not a migration. CallerModuleProgress.status is a plain string whose comment lists the values in use, so WAIVED needs no schema change. And three of the knobs described as engine constants — loMasteryThreshold, assessmentReadinessThreshold, skillScoringEmaHalfLifeDays — are live cascade settings with working resolvers. Readiness in particular is built: buildAssessmentReadinessDirective returns ready / not_ready / unknown and is wired into compose. It returns null only because no course has set the number.

IF YOU DID FOUR

Fidelity audit (M), the WAIVED status (S), advance-rule reconciliation (S) and switching profiling off (S) come to roughly a fortnight between them. They close six rows, remove the two findings hardest to defend in an interview, and none of them waits on anyone outside the team.

Where the two cheapest tests sit

Fidelity audit. Fifty transcripts, checked against the authored model: was one rung taught, was there one probe, was the silence held, did the sibling re-ask happen. No external party needed, and it tests the thing the product actually claims.

Assessor agreement. One experienced SIAS assessor, thirty transcripts, blind tiering against the same rubric. Moves concurrent validity from absent to measured.

Together they cover both halves of the question an education expert will ask: does the teaching happen, and is the measurement real.
